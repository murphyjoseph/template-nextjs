For this interview you will code on your own machine in any environment and with any libraries and tools you’re comfortable with.. We'll check-in about every 20 minutes to get an update from you - during these check-ins it will work best if you then share your screen to share progress. For the last 15 minutes we'll talk through where you arrived and where you would spend more time and how you might productionize the work you started. Finally, it will be great if you can share a zip file of your code with us, either via Dropbox, Google Drive, or a gist (GMail blocks zips). The goal of this interview is to learn what you can do in a fixed amount of time to deliver the best user experience possible (and what that means to you) - we’re hoping to see your creativity and ingenuity and debugging skills over something that merely works.
