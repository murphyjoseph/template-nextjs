# PROMPT: Generate project rundown

Using the template in ./docs/templates/rundown.md, create a rundown for this challenge. Follow these rules:

1. Read the challenge requirements carefully (if not provided ask for them). Separate what is explicitly required from what is optional, bonus, or "nice to have."
2. Core Requirements should only contain tasks that are necessary for a passing submission. Order them by dependency, not difficulty.
3. If a core requirement is complex or risky, move it to Deferred Hard Parts instead. It still needs to get done, but I'll tackle easier core tasks first so I have a working baseline sooner.
4. Everything not required goes in Extra Credit, ordered by impact.
   Time estimates should be realistic and account for debugging, not just writing code.
5. Be specific with task descriptions. "Build the form" is bad. "Create controlled form with name, email, and phone fields that validates on submit" is good.
6. Call out ambiguities in the requirements. Don't make silent assumptions.
7. Review and make sure nothing was missed.
8. Add this rundown into ./docs folder at project root.
9. Update the CLAUDE.md file at project root to update the checklist as it completes tasks.
